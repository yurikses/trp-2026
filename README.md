
## Название проекта
Rubdiff
## Назначение
Автоматизированный сбор и сравнение цен на товары из различных интернет-магазинов для поиска наилучших предложений.
## Целевая аудитория
  - Покупатели, желающие сэкономить
  - Аналитики рынка
  - Владельцы интернет-магазинов

## Описание предметной области
Система агрегирует данные о ценах на товары из множества онлайн-магазинов, предоставляя пользователям актуальную информацию для принятия решений о покупке.
## Основные сущности

  - Пользователь - зарегистрированный клиент системы
  - Товар - карточка товара с характеристиками
  - Магазин - источник данных о ценах
  - Цена - стоимость товара в конкретном магазине
  - Категория - группа товаров

## Основные функции

  - Поиск товаров по названию и категориям
  - Сравнение цен в разных магазинах
  - Отслеживание изменения цен
  - Настройка уведомлений о снижении цены
  - Добавление товаров в избранное
